# Datavault

A reader for community wiki archives, built as an installable web app (PWA).

Datavault does not host, store or bundle any article content. Every article is
fetched live from the source wiki when you open it, and each article links back
to its original page. All illustrations shown in the app are generated
procedurally at runtime from the article title — no artwork is shipped or
downloaded.
